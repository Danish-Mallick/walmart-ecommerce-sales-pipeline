Engineering decisions behind the visuals

The project is built to be rerunnable and testable.

⛓

Validated 1:1 joins

Duplicate keys stop the pipeline before a many-to-many merge can quietly inflate sales.

✓

Schema as a contract

Required columns, null handling, valid dates and filtering rules are enforced before output is published.

⚙

CI + reproducibility

Tests and a pipeline smoke run validate that transformations, marts and expected outputs continue to work together.
